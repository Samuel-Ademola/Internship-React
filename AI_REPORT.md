# AI-Assisted Development Report

## Project Overview

This project is a React + Vite movie search application that integrates with the OMDb API for movie discovery and Firebase for authentication and favourites persistence.

The application allows users to search for movies, create an account, log in, and save favourite movies to their personal Firestore collection.

The project follows an MVVM-inspired structure to separate UI components, application logic, and external services.

---

# How AI Assisted During Development

AI was used as a development assistant throughout the implementation process.

AI helped with:

- Creating the initial React project structure.
- Suggesting an MVVM-inspired architecture.
- Generating reusable React components.
- Integrating the OMDb movie search API.
- Setting up Firebase Authentication.
- Creating Firestore services for storing favourites.
- Implementing protected routes.
- Debugging errors during development.
- Improving UI responsiveness and styling.
- Reviewing code structure and suggesting improvements.
- Writing and improving project documentation.

AI helped speed up development by providing suggestions and explanations, but all generated code was reviewed, tested, and modified before being included in the final application.

---

# Manual Improvements and Refactoring

After reviewing AI-generated code, I made several manual improvements:

- Reorganized files into a cleaner folder structure.
- Adjusted the architecture to follow an MVVM-inspired pattern.
- Improved naming conventions for components, functions, and variables.
- Moved Firebase and API logic into separate service files.
- Fixed authentication state management issues.
- Improved protected route behaviour.
- Updated UI layouts for better responsiveness.
- Improved consistency between pages and reusable components.
- Added breadcrumb navigation and footer layout.
- Reviewed and corrected bugs discovered during testing.
- Updated README documentation with setup instructions.

# Reflection

This project showed how AI can be used effectively as a programming assistant.

AI reduced development time by helping with repetitive tasks, debugging, and exploring possible solutions. However, understanding the generated code, testing functionality, and making architectural decisions remained my responsibility as the developer.

The final application was improved through a combination of AI assistance, manual coding, testing, and refactoring.
